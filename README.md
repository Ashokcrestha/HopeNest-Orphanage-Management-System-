HopeNest is a web-based Orphanage Management System that helps manage children’s records, donations, and adoption processes in one platform.
It allows users to view child details, donate, and apply for adoption بسهولة through a simple interface.
A key feature is the Child Matching Algorithm, which connects adopters with suitable children based on their preferences.
Overall, HopeNest improves efficiency, transparency, and simplifies orphanage management.


HopeNest is developed using modern web technologies for both front-end and back-end.
For the front end, HTML is used to design pages, CSS for styling, and JavaScript to make the system interactive and user-friendly.
For the back end, PHP is used to handle server-side logic and database operations.
The system runs on XAMPP, which provides an environment for development.
For the database, MySQL is used to store and manage all system data securely.
